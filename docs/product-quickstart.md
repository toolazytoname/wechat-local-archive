# 微信聊天档案：使用指南

## 打开

在已配置的 Mac 上双击桌面的「微信聊天档案」。无需启动微信，无需输入终端命令。不要删除已安装的运行环境或本机 data 目录。

## 六个入口

- **聊天**：浏览聊天，搜索消息，查看已恢复的图片、下载文件、打开原链接。缺失附件不等于能凭空恢复。
- **我的画像**：先确认哪些发送者是自己，再选择范围整理原话。能看任务进度、取消任务，生成后可导出报告。
- **好友画像**：选择好友并补充关系信息；区分本人原话、引用和你的补充信息。
- **稍后读**：将指定收藏会话整理成资料库，阅读图片和文件，打开链接，粘贴正文、写笔记、标已读。AI 整理前先预览发往哪里、多少正文，再单独批准；结果是待核对的学习草稿和复习问题。
- **导出**：导出聊天资料。画像页可导出报告；稍后读可导出离线学习包。生成后可在 Finder 中打开。
- **设置**：身份、人物关系和引擎配置；发现旧资料时可明确核对账号后补入缺失记录，不覆盖当前编辑。

## 重要边界

本机摘录不是人格鉴定。远端画像默认只抽取最多 80 条、每条 400 字，不是全量智能分析。取消会阻止结果继续发布，但不能撤回已经发送给模型的数据；进行中的请求可能要等超时才结束。本机任务失败后可重新开始，不是断点续跑。云端任务不自动重放，必须再次批准。

原始档案始终标为 live-db，备份 2 尚未验证。只有标题的网页不能自动当成取得正文；OCR、语音转写和任意微信版本兼容不在已完成范围内。
