# 怎么打开、查看和导出

## 已经为你配置好本机入口时

双击桌面上的 **微信聊天档案.app**。它会启动本机服务并打开浏览器；不用自己开终端，也不用记端口。重复双击会使用同一个服务。关闭网页不会删除数据，下次再双击即可。第一次整理大型档案可能需要等待一两分钟。

这是本机生成的启动入口，不是腾讯客户端，也不是经过公证的公开DMG。不要为了运行它关闭系统保护。安装目录和原始档案目录暂时不要搬走；入口需要它们。

## 首页怎么用

- **打开聊天记录**：打开最近保存的档案。左侧搜群名或联系人，右侧看内容。
- **导出数据**：打开导出面板。选择一个聊天、多个聊天或全部；日期留空表示不限时间。
- **选择已保存的档案**：打开其他历史档案，不会将它们混在一起。
- **读取新消息 / 首次导入**：高级读取流程。已有档案不是实时同步，当前微信build未验证时会明确提示。

## 导出格式怎么选

| 格式 | 适合谁 |
|---|---|
| Markdown | 直接阅读、整理文档 |
| JSONL | 完整结构化分析，一行一条消息 |
| CSV | Excel筛选、统计 |
| HTML | 双击可打开的离线聊天网页 |

默认选择易读版。原始资料版可能含微信内部字段，不建议直接上传。保存成功后点 **在访达中显示**，不用复制路径。

“只导出可读文字”会排除非文字消息；要保留尽可能完整的信息就不要勾选。结束日期/时间不计入范围。引用、转发可能只显示部分预览，原档案保留原始字段。

## 批量导出资料

批量交付包含三份独立ZIP及同名本机目录。先读各包的`先读我.md`，再用`analysis/chunks/`的分卷；方便分批阅读和处理。分析版保留时间、发送者、会话、消息类型、来源定位、可读正文、链接、卡片和附件引用状态。

ZIP不含`raw-local-only/`；它只在本机目录里保留完整原始记录。分析版也仍有私人聊天，不等于匿名化。分享给任何外部服务都是你主动向第三方提供资料，工具本身不会上传。

## 图片、文件和链接

原网页链接可点击确认后打开；目标网站可能要求登录或已经失效。图片/文件卡片不等于附件原件：没有恢复的会明确说明。缺失附件不代表内容为空，也不表示已经恢复。

有本地可读附件时，图片直接显示，点击“查看大图”放大；文件卡片可下载。只有缩略图时会标注“预览”，不会冒充原图。视频如果只取得封面则显示封面，不会显示无法播放的播放器。

旧的导出ZIP及离线HTML不会自动增加新附件；本次恢复的二进制文件保存在所选档案的 `media/`，聊天查看器从这里读取。

## 如果打不开

- 等待片刻再双击，不要同时开多个复制品或重装微信。
- 提示服务仍在准备：让它完成，不要手动结束Python进程。
- 提示档案变化：回首页重新打开该档案并重新预览导出范围。
- 所有内容仍留在本机；退出工具不会退出微信登录或删除聊天。
