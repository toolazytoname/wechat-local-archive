# 实施状态（相对设计冻结稿）

这是功能状态，不是又一份设计。合成测试通过不等于新用户首次读取完成，也不等于云端画像已批准。

## 已落地

- P0：派生 `insights.sqlite`、is_self 身份审计、用户补充人物/会话用途。重名不会自动合并。
- P1：主导航「聊天 / 我的画像 / 好友画像 / 稍后读 / 导出 / 设置」。原聊天、搜索、导出保留。
- P2：收藏学习导入含链接/图片/文件/短备注；能接到已恢复附件；阅读页用本机 `/api/media` 显示图片/音视频/文件；学习包 Markdown/HTML 写相对媒体路径和收藏备注。缺附件恢复后再整理会升级 `content_state`，不覆盖笔记和已读。
- P3：本机摘录 + Grok CLI / BYOK。云端必须 JSON `true` 的一次性范围票据；`UPDATE used=1 WHERE used=0` 原子消费；身份修订后旧票拒绝。字符串/跨好友/过期/顺序重放拒绝。默认禁止重定向带走 Authorization。
- P4/P5：范围 SQL 统一用于统计与取材（单数 `conversation_id` 与复数、时区/日期-only 都先规范化；毫秒边界在二次规范化后保持）。证据按冻结 UID 重建，未知 UID 整条拒绝。自动发布只接受完整句段原话；不删除主语或裁去条件，否定与假设原样保留且不当作本人意图。角色对调、否定翻转、时间/已然冲突不得因字符相似写成受支持复述。重复原话合并。排除修订对后续取材生效。
- P6：无模型时只做「正文摘录」，不称为语义梳理完成。远端完成态也只表示可核对的完整句段原话，不是人格鉴定。
- P7：静态资源随 package-data（含 profiles/learning/shell）。隔离安装需重新构建 wheel 后安装；本轮不宣称旧桌面包已自动更新。本机已另外完成新版 wheel 安装、桌面入口替换和服务健康检查；这不是声称其他用户的旧桌面包已自动更新。旧派生库只有完整 source_revision 一致或已有 archive_root 可信绑定时才迁移；唯一无归属旧库也标 needs_recovery。初始化使用进程退出自动释放的 flock；迁移在独立 staging 完成，正文按 SHA-256 核验、临时文件替换，最后原子发布 SQLite。迁移期间其他请求返回 migration_in_progress；新旧都非空（包括旧版半迁移库）保全为冲突，不重放覆盖新笔记。档案更新后旧报告标 `stale`，不删笔记和修订。

## 仍缺 / 降级说明

- 远端画像仍是有限抽样（默认最多 80 条、400 字），不是全量分层分析。`processed_count` 为实际写入观察数，`candidate_count`/`sampled_count` 写入 result_json 并在页面区分；页面采用后台任务，支持进度、取消及本机失败任务重新开始（不是断点续跑）。画像报告导出含 JSON、Markdown、离线 HTML 与校验清单。
- 文章 AI 整理需逐次预览并批准，按正文分段生成带引文的学习草稿和复习问题；引文核对不等于含义正确。正文更改会拒绝旧任务发布。
- 外部网页抓取默认关闭。OCR / 语音转写未做。
- 公开 `verified_builds` 与新用户首次读取仍未完成。本机桌面服务已通过独立安装与入口切换更新；其他用户需安装新版。

私有人物关系不得写入本文件。

## 本轮修复验收边界

- 第四轮 D01–D04 已有回归测试：无归属隔离、可信绑定、截断文件修复、损坏源拒绝、并发初始化禁止暴露目标、锁持有进程退出、旧半迁移保留新笔记、原话主语/条件/否定。
- needs_recovery / conflict 已提供显式恢复入口：核对账号和文件指纹后只补缺失记录，不覆盖当前编辑、不导入授权票据。
- 图片/文件、正文粘贴、笔记重开及停服后离线媒体使用合成浏览器验收；不代表真实模型完成画像，也正式桌面版是否更新须单独验证；本机已完成安装、入口替换和资源 HTTP 200 验证。

## 易用性修订

- 我的画像只保留一个「生成我的画像」主操作；移除主流程中的本机摘录按钮。范围自动读取、直接说明，发送前用新鲜预览和明确确认弹窗，不保留容易失效的批准勾选。
- 好友页直接读取会话 API，提供昵称/备注搜索、选择反馈和对应好友历史报告；修复读取不存在的 `window.state` 导致好友列表为空的问题。
- 稍后读可直接选择收藏会话并整理；保留完成反馈，提供标题/备注/笔记搜索、阅读状态筛选，导出有忙碌态、错误及重试反馈。
- AI 连接测试只发送固定虚构句子，不读取聊天，不生成正式报告；云端错误分类但不暴露服务原始响应。Grok 仅在明确不支持命令行 schema 参数时重试，不对登录或一般网络失败盲目重发。
- 画像模型指令要求 statement 保留完整原句，与严格证据核验契约一致；没有为“有结果”而放松证据或敏感推断限制。
- 浏览器验收脚本 `tests/browser_usability.cjs` 使用真实 HTTP 路由与虚构模型，覆盖确认取消、好友选择与重开、学习导入、失败重试、移动宽度。不代表已对真实档案执行云端分析。
