# 普通用户视角验收（2026-09-11）

## 方法与结论

本轮从 Finder 桌面入口启动，在现有 Chrome 中逐步点击、输入、切换页面并阅读实际结果。没有注入 `window.state`、伪造接口返回或直接调用生成 API 代替 UI。AI 流程使用内置虚构示例和实际配置的 Grok；真实聊天没有发给云端。

**结论：基础资料工作流可操作；画像内容质量未达成产品目标，不能以技术测试通过替代产品验收。**

## 本轮修复

- 页面重新进入时，按画像类型及准确范围查找正在运行的任务，恢复进度，不重新发起模型请求。
- 停止为已经移除的视图继续轮询；生成中禁用引擎变更。
- 历史任务完成后直接加载报告，状态标题也随任务状态同步。
- 引用跳转使用真实会话元数据，避免昵称退化为内部 ID、时间为空。
- 已读条目重新打开后，已读按钮仍为禁用态。
